
# 🤖 Rule Based AI Chatbot — A simple Python chatbot built with rule-based logic.

This project is a command-line chatbot developed in Python that responds to predefined user commands using conditional logic and dictionaries. It demonstrates the fundamentals of chatbot development while keeping the code clean, readable, and beginner-friendly.

---

## 🚀 Features

- Responds to greetings like `hello` and `hi`
- Displays the current date and time
- Answers basic questions such as "What's your name?"
- Includes a built-in help menu
- Recognizes appreciation messages
- Supports conversation exit commands
- Handles unknown inputs with a friendly error message
- Uses a dictionary for organized and maintainable responses

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Modules:** `datetime`
- **Concepts Used:**
  - Dictionaries
  - Conditional Statements (`if`, `elif`, `else`)
  - Loops (`while`)
  - User Input Handling
  - String Methods
  - Rule-Based Logic
